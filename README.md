# Budget Warden

Budget Warden is a source-available native macOS budgeting app (iOS, Android and Windows support planned). It stores budgets as plain `.budget` files. 

## Requirements

- macOS
- Xcode

## Development

XCode Project:

```sh
open macos/BudgetWarden.xcodeproj
```
